SAMSOLUTION — MERCADO PAGO PIX

IMPORTANTE
O Access Token do Mercado Pago é uma credencial secreta. Ele NÃO deve ficar dentro do ZIP, HTML, JavaScript do navegador ou GitHub.

NA VERCEL
1. Abra o projeto do SamSolution.
2. Settings > Environment Variables.
3. Crie:
   MP_ACCESS_TOKEN = SEU ACCESS TOKEN DO MERCADO PAGO
4. Crie também:
   POSTGRES_URL = CONNECTION STRING DO SUPABASE (Transaction Pooler)
5. Opcional:
   PRODUCT_NAME = Google AI Pro
   PRODUCT_PRICE = 0.01
6. Salve e faça Redeploy sem cache.

PIX
A API do backend usa POST /v1/orders do Mercado Pago, QR dinâmico, X-Idempotency-Key e lê type_response.qr_data. O Access Token fica somente no servidor.

TESTE
Abra /api/health no domínio da Vercel. O resultado deve mostrar:
  database: true
  mercadopago: true

Depois faça uma compra de teste. O fluxo é:
checkout > QR PIX > consulta da Order > pagamento aprovado > reserva de código > entrega.

SEGURANÇA
O token que apareceu em uma imagem/conversa deve ser considerado exposto. Gere/rotacione um novo Access Token no Mercado Pago antes de produção.
