# Painel Admin sem senha

A versão solicitada usa apenas:

`admin`

Não existe campo de senha.

O painel envia `X-SamSolution-Admin: admin` para as funções administrativas.

## Atenção

Este modo é deliberadamente simples e **não oferece autenticação forte**. Não use como modelo de segurança para uma área administrativa pública. Se o site for colocado em produção com dados sensíveis, adicione autenticação real.
